# Email Spam Classifier

A lightweight NLP and supervised-learning project that classifies an email or SMS message as **Spam** or **Ham**. It includes reproducible training and evaluation, a command-line predictor, visual reports, and a responsive Flask web interface.

> **Dataset note:** This project downloads and keeps `data/spam.csv` from the UCI SMS Spam Collection when available. If that download is unavailable, it creates a clearly labeled synthetic demo dataset; scores from synthetic data are not evidence of real-world performance. The SpamAssassin public corpus can also be used by replacing `data/spam.csv` with a CSV containing `v1`/`v2` (or `label`/`text`) columns and `ham`/`spam` labels. Remove `data/dataset_metadata.json` before training on a replacement dataset so its provenance is recorded as user-provided and unverified.

## Features

- URL, number, punctuation, and stopword cleanup with NLTK tokenization and lemmatization.
- TF-IDF unigrams and bigrams, with a 5,000-feature cap.
- Stratified 80/20 evaluation of Multinomial Naive Bayes, Logistic Regression, and calibrated Linear SVM.
- Best-model selection by F1, with false-positive rate as the tie-breaker.
- Saved model, vectorizer, metrics, comparison CSV, keyword chart, word clouds, confusion matrix, and comparison chart.
- Cached real-time prediction and a JSON API with input-size validation.
- Flask UI with spam/ham status, confidence, model metrics, keywords, and plots.
- Render Blueprint deployment configuration for Python 3.11.9.

## Technology

Python 3.11, pandas, NumPy, scikit-learn, NLTK, Matplotlib, Seaborn, wordcloud, joblib, Flask, and Gunicorn.

## Installation

Python 3.11 is recommended (the deployment service is pinned to Python 3.11.9). From the project root in PowerShell:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

The first data preparation/training run downloads NLTK resources (`stopwords`, `punkt`, `punkt_tab`, and `wordnet`) automatically. An internet connection is needed for the initial downloads unless those resources are already cached.

## Run locally

Commands below assume the virtual environment is activated and the current directory is the project root.

```powershell
# Train all three classifiers, select the best one, and save model artifacts/results
python -m src.train

# Recreate the metric report and comparison CSV from the saved held-out test set
python -m src.evaluate

# Generate the spam-keyword chart, word clouds, confusion matrix, and comparison chart
python -m src.visualize

# Interactive prompt; type "quit" to exit
python -m src.predict

# Start the web interface at http://127.0.0.1:5000
python app.py
```

`src.train` creates the dataset if it is not present. `app.py` trains missing model artifacts and generates missing visualizations before serving requests.

## Example prediction

```text
Email text: Congratulations! You have won a free prize. Claim your reward now at http://claim.example
Spam (confidence: 99.6%)

Email text: Hi, are we still meeting for lunch today? Please let me know.
Ham (confidence: 100.0%)
```

Confidence depends on the selected model and training data and should not be treated as a guarantee.

## HTTP API

- `GET /` — responsive web UI.
- `POST /predict` — JSON input `{"text":"..."}` (or `{"email":"..."}`); JSON response includes `label` and `confidence`.
- `GET /api/keywords` — top spam-associated features.
- `GET /health` — health check, returns HTTP 200.
- `GET /outputs/<filename>` — generated chart files.

Example request:

```powershell
curl.exe -X POST http://127.0.0.1:5000/predict -H "Content-Type: application/json" -d "{\"text\":\"You have won a free prize. Claim now!\"}"
```

Empty messages are rejected, and messages longer than 20,000 characters are rejected. Do not submit sensitive or personal information.

## Render deployment

1. Push this project, including `data/spam.csv`, to a GitHub repository.
2. In Render, choose **New + → Blueprint** and connect the repository containing `render.yaml`.
3. Review the Blueprint and create the `email-spam-classifier` web service. Render reads the build and start commands, health check, and `PYTHON_VERSION=3.11.9` from the Blueprint.
4. The build installs the pinned dependencies, downloads/uses the dataset, trains the models, and generates the visualizations. Check the build log for dataset or NLTK download errors.
5. Wait for deployment, then open the generated `onrender.com` URL. Verify `/health` returns `{"status":"ok"}` and submit a sample message on the home page.

The Gunicorn configuration uses one worker to stay within the free-tier memory limit. The model is loaded once per process and predictions reuse it. Render's free service may sleep while idle and can take time to wake up.
